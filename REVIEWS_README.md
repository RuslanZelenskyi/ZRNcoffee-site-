# Как собирать отзывы после доставки

1. Когда посылка доставлена, отправьте клиенту в Viber/Telegram:

   Дякуємо за замовлення! Якщо кава сподобалась — залиште, будь ласка, короткий відгук (1 хвилина):
   https://zrncoffee.com.ua/review/?o=НОМЕР_ЗАМОВЛЕННЯ

   Для русскоязычных: https://zrncoffee.com.ua/ru/review/?o=НОМЕР_ЗАМОВЛЕННЯ
   (по желанию добавьте &p=epic — сорт подставится автоматически; id сорта = адрес /coffee/<id>/).

2. Отзыв придёт на почту (Web3Forms) и в лист «Відгуки» Google-таблицы (после обновления Apps Script и нового Deploy → New version).
   Номер заказа сверяется с листом заказов: «Так» = подтверждённая покупка.
3. Страница /review/ закрыта от индексации и не попадает в sitemap.
